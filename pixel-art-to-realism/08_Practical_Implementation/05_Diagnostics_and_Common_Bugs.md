# Диагностика артефактов и устранение неполадок (Diagnostics & Common Bugs)

## 1. Краткое описание
В этой статье собрано практическое инженерное руководство по визуальной и программной диагностике генеративных дефектов. Приводится систематизированная таблица визуальных артефактов (размытие, анатомические мутации, сеточные структуры, потеря контраста), их глубинные математические причины и экспресс-рецепты устранения через калибровку гиперпараметров.

---

## 2. Интуитивное объяснение: Глаз диагноста

При отладке классического кода программист смотрит на стектрейс ошибки (`TypeError`, `IndexError`).  
При отладке генеративного пайплайна код выполняется без единой ошибки, но на картинке вместо фотореалистичного воина получается пугающий мозаичный монстр с четырьмя глазами.

Инженер компьютерного зрения обязан уметь **«читать визуальные артефакты»**:
- Если на щеке видна сетка — значит, перетянут вес Tile или детектор Canny захватил пиксельные границы.
- Если у персонажа поплыли пальцы — значит, ослаблен вес Depth Anything или перекручен CFG scale.
- Если цвета стали тусклыми — забыли включить Reinhard трансфер.

## 3. Систематическая таблица визуальных дефектов и решений

| Визуальный симптом | Корневая причина | Экспресс-решение (Quick Fix) |
|---|---|---|
| **Сетка кубиков на лице / одежде («Сеточный гроб»)** | Canny детектор обвёл пиксели; либо вес ControlNet-Tile слишком высок ($w > 0.90$). | 1. Заменить Canny на билатеральный фильтр ($\sigma=75$).<br/>2. Снизить вес Tile до $0.72 – 0.75$. |
| **Мутации анатомии (3 руки, лишние пальцы)** | Слишком высокий Guidance Scale (CFG $> 8.5$), подавляющий структурный адаптер. | 1. Снизить CFG scale до $6.5 – 7.0$.<br/>2. Увеличить вес ControlNet-Depth с 0.2 до 0.35. |
| **Пластиковое лицо без пор и текстур («Мультяшность»)** | Адаптер ControlNet работал на 100% шагов, не дав базовой модели дорисовать микропоры. | Установить параметр отключения адаптера: `controlnet_end = 0.85`. |
| **Смена класса объекта (лук превратился в посох)** | Вес ControlNet-Tile слишком мал ($w < 0.50$); модель сгаллюцинировала по промпту. | 1. Повысить вес Tile до $0.75$.<br/>2. Уточнить текстовый промпт через VLM (Florence-2). |
| **Тусклые, ненасыщенные цвета** | Смещение дисперсии в латентном пространстве VAE. | Применить Reinhard Color Transfer в пространстве $Lab$ к оригинальному спрайту. |
| **Черная кайма вокруг силуэта на прозрачном фоне** | Прозрачные пиксели были закодированы как RGB `(0, 0, 0)`. | Залить фон нейтральным серым RGB `(127, 127, 127)` перед VAE кодированием. |
| **Падение с ошибкой `MPS out of memory` на Mac** | Декодер VAE попытался декодировать изображение $1024\times 1024$ одним монолитным тензором. | Включить тайлинг VAE: `pipe.enable_vae_tiling()`. |

## 4. Практическая реализация: Инспектор промежуточных тензоров

```python
"""nn_upscaler.diagnostics.inspector: Automated diagnostic inspection of intermediate tensors."""

import numpy as np
import torch
from PIL import Image


class TensorSanityInspector:
    """Утилита мониторинга аномалий в тензорах условий и выходов."""

    @staticmethod
    def inspect_control_map(condition_pil: Image.Image) -> dict:
        """Проверка направляющей карты на наличие высокочастотной сетки пикселей."""
        arr = np.array(condition_pil.convert("L"))
        # Быстрое преобразование Фурье для анализа пространственных частот
        f_transform = np.fft.fft2(arr)
        f_shift = np.fft.fftshift(f_transform)
        magnitude_spectrum = 20 * np.log(np.abs(f_shift) + 1e-6)

        # Пики на высоких частотах сигнализируют о наличии сетки кубиков
        h, w = arr.shape
        high_freq_ring = magnitude_spectrum[0 : h // 8, 0 : w // 8].mean()

        has_grid_danger = high_freq_ring > 180.0
        if has_grid_danger:
            print(
                "[!] ВНИМАНИЕ: Направляющая карта содержит высокочастотную сетку! Рекомендуется применить билатеральное размытие."
            )

        return {
            "high_freq_energy": float(high_freq_ring),
            "has_grid_danger": has_grid_danger,
            "min_val": int(arr.min()),
            "max_val": int(arr.max()),
        }
```
